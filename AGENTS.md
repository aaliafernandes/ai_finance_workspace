# AI Finance Applications — Project Guidance

This workspace is for coursework in AI Finance Applications.

## Working principles

- Treat all analyses as educational, not personalized investment advice.
- Clearly distinguish historical results, assumptions, and forecasts.
- Cite the source and retrieval date for market, company, economic, or academic data.
- Use reproducible workflows: keep raw data separate from processed data and document transformations.
- Prefer Python notebooks/scripts with readable comments and pinned package requirements when applicable.
- Do not place API keys, passwords, account details, or private student information in tracked files.

## Expected deliverables

- Explain financial concepts in plain language before introducing formulas or code.
- Include assumptions, methodology, limitations, and interpretation with every model or analysis.
- Label charts with units, date ranges, sources, and a descriptive title.
- For predictive models, use an appropriate time-based train/test split and report evaluation metrics.
- Keep course assignments organized in a folder per module or project.

- KISS: keep it simple.
